FEED FORMULA - installable app (free)

Put these files on free hosting (GitHub Pages), then install from Edge:
index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png, icon-maskable-512.png, apple-touch-icon.png

After install: Start menu / Desktop icon, own window, works offline.
Your data (formulas, prices, masters) stays on each computer, not on GitHub.
Move data from the old FeedFormula.html: Export all (backup) there -> Import backup in the app.
